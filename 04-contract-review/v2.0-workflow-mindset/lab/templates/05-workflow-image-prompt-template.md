# Template — Prompt sinh ảnh Workflow Infographic

> Dùng cho BT5. Thay thế nội dung trong ngoặc vuông `[...]` bằng thông tin use-case của bạn.

---

## Phương án 1: Before-After

```text
Vẽ infographic so sánh Trước-Sau cho quy trình "[Tên quy trình]":

TRƯỚC (As-is):
- [Mô tả vấn đề 1]
- [Mô tả vấn đề 2]
- [Mô tả vấn đề 3]

SAU (To-be):
- [Mô tả cải tiến 1]
- [Mô tả cải tiến 2]
- [Mô tả cải tiến 3]

Phong cách: infographic chuyên nghiệp, tiếng Việt, màu sắc tươi sáng.
```

---

## Phương án 2: Storytelling

```text
Vẽ sơ đồ kể chuyện "Một ngày làm việc" cho quy trình "[Tên quy trình]":

Khung 1: [Mô tả tình huống ban đầu]
Khung 2: [AI Agent can thiệp như thế nào]
Khung 3: [Người dùng tương tác / duyệt]
Khung 4: [Kết quả cuối cùng]

Phong cách: storytelling illustration, tiếng Việt, dễ hiểu.
```

---

## Phương án 3: System Architecture

```text
Vẽ sơ đồ kiến trúc hệ thống cho "[Tên quy trình]":

Tầng 1 - Entry: [Nguồn dữ liệu đầu vào]
Tầng 2 - Processing: [AI Agent + n8n xử lý]
Tầng 3 - HITL: [Giao diện duyệt cho người dùng]
Tầng 4 - Output: [Kết quả đầu ra + lưu trữ]

Phong cách: system architecture diagram, tiếng Việt, chuyên nghiệp.
```
