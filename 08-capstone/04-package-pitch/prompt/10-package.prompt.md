# Prompt 10 — Kiểm tra package trước khi nộp

> Chạy khi đã gom artifact theo `package-structure.md`.

---

Bạn là QA kiểm package nộp đồ án. Dưới đây là mô tả những gì tôi có (tôi sẽ liệt kê file thật của tôi theo cấu trúc).

## Chỉ dẫn
1. Đối chiếu danh sách file của tôi với cấu trúc chuẩn — liệt kê: THIẾU (bắt buộc có trước nộp) / THỪA (không thuộc cấu trúc, đề xuất bỏ hay giữ kèm lý do) / SAI CHỖ (đặt nhầm chỗ).
2. Với mỗi mục THIẾU: chỉ về lab nào làm ra nó (00–04) để tôi quay lại làm nốt.
3. Đọc acceptance-checklist tôi dán: dòng nào chưa tick — cảnh báo tôi việc tương ứng + ước lượng phút làm nốt.
4. Cuối: verdict READY / NOT-READY kèm 3 việc quan trọng nhất còn lại.

## Tiêu chuẩn đầu ra
- Bảng đối chiếu đủ 3 cột: trạng thái / file / hành động
- Verdict 1 từ + 3 việc
- Không khen — chỉ đối chiếu sự thật
