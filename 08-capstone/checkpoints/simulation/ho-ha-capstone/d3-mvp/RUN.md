# RUN.md — chạy lại app trong ≤3 bước

1. Mở file `index.html` bằng trình duyệt (double-click, không cần server, không cần API key).
2. Dán 1 tin yêu cầu bảo hành vào ô (3 tin mẫu trong `../d2-n8n-e2e/e2e-test.md` mục Bộ input mẫu).
3. Bấm **Xử lý** — kết quả hiện dưới (đề xuất + lý do + câu trả lời khách + dòng log CSV).

Ngày xử lý mặc định 23/08/2026, đổi được ở ô date để test hết các trường hợp còn/hết bảo hành.
