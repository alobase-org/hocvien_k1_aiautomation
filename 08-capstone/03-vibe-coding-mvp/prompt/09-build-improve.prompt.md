# Prompt 09 — Build MVP + vòng cải tiến (chạy trong công cụ build: AI Studio Build / Coding Agent)

---

## Bối cảnh
Spec-kit dưới đây là đặc tả đầy đủ. App exemplar tôi tham khảo: `04-contract-review/app/` (B4) — React, cấu trúc src gọn.

## Chỉ dẫn (lần build đầu)
1. Đọc spec-kit. Xây web app 1 trang đúng phạm vi MVP — không thêm tính năng ngoài spec.
2. Giao diện: form nhập input của use case → nút xử lý → vùng hiển thị output.
3. Xử lý: bước quy tắc cứng làm bằng code; bước phán đoán gọi AI (dùng API/model có sẵn trong công cụ).
4. Sinh xong: hướng dẫn tôi preview và chạy test scenario #1 của spec.

## Chỉ dẫn (các vòng cải tiến — gửi lại prompt này kèm yêu cầu)
1. Chỉ sửa đúng 1 yêu cầu tôi nêu — không đụng phần khác.
2. Sau sửa: nêu tôi cần test lại scenario nào.

## Tiêu chuẩn đầu ra
- App chạy trong preview/local, thao tác input → output hoàn chỉnh 1 lần
- Code có chú thích ngắn tiếng Việt ở các file chính
- Không claim tính năng chưa có; phần thiếu ghi rõ "chưa làm"
